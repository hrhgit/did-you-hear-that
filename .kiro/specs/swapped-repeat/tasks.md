# Tasks: swapped repeat

Work through the tasks in order. Each task ends with its own checks holding, and after every task `npm run typecheck`, `npm test`, `npm run lint` and `npm run check:copy` pass. Requirement numbers refer to `requirements.md`; decision, question and CP numbers to `design.md`.

The tasks are done in five batches, marked below. A batch is what one unattended run can finish. It may also end after any task inside it, because every task leaves the four commands passing.

**Commits.** Tasks do not commit. No task runs `git add`, `git commit`, `git push`, `git remote`, `git config`, `git stash`, `git reset`, `git checkout` or `gh`. After the tasks a separate run makes one commit per group of files with a one-line message; each task below ends with the proposed message (imperative, no full stop) and the exact list of files it covers. If a task stops early, its report says which of those files it changed. What a task must record (property times, a counterexample, the measurement printed again) goes in `design.md` or a README, in the place the task names (D25). Before ending a task, run `git status` and check that only the files the task names were created or changed. The two files the owner's coordinator changed for Q8, `src/ui/visit/screen-of-snapshot.test.ts` and `src/ui/result/picture-sheet.test.ts`, were committed before task 1 (`Cast three test literals ahead of the swapped repeat contract`) and no longer show as changed in the working tree; they are not this spec's and go in no task's commit.

**Boundaries.** The project owner builds the screen by hand in the same working tree. No task creates or changes anything under `src/ui/`, `tests/e2e/` or `tests/properties/screen-leak/`, any CSS or HTML file (`index.html`, `listen.html`, `result-sheet.html`, every `.css` file), `src/main.ts`, the root `README.md`, anything under `src/engine/`, `src/audio/` or `.kiro/steering/` (R23.1). Under `src/storage/` the only changes are the method `changePayload` and its test, in task 14 (Q5, R13.8), and the one line of `src/storage/README.md` that describes `changePayload`, in task 18 (R23.4). Tasks change only the files listed in "Files" in `design.md`, and in `src/session/visit-flow-types.ts` and `src/session/result-page-types.ts` they only add (R23.2).
