# .kiro

Kiro's working files for this project. They stay in the repository.

- `steering/` holds the rules every change follows: product, structure, technology, audio safety, wording and the hearing method.
- `specs/` holds one directory per spec, each with its requirements, design and tasks.
- `hooks/` holds commands or prompts that run on events such as a file save.
- `agents/` holds custom agent configurations.
- `settings/` holds Kiro settings, such as model defaults and MCP configuration.

Kiro reads only these subdirectories. This README affects nothing.
